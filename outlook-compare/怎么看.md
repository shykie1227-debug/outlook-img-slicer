# 怎么对比

两张网页里是**同一张 960x3600 的原图、同样的 3 个可点击按钮**，唯一区别是邮件正文的 HTML 表格结构。

看什么：
1. 背景是连续垂直渐变，任何 1px 缝隙都会把渐变切断成一条亮线。
2. 每 300px 有一条 1px 黑色标尺线，用来确认上下两段有没有错位。
3. 橙色框是按钮位置，三个按钮的链接应能点击。

建议验证方式（按可信度从高到低）：
- **Word**（Windows）：用 Word 打开 .htm。Word 和 Outlook 邮件正文
  用的是同一个排版引擎，看到什么 Outlook 里就是什么。
- **Outlook**：新建邮件 → 直接把 .htm 文件拖进正文（或用
  「附加文件 > 插入文件」后选「作为文本插入」）。
- 浏览器：只能看结构差异，不代表 Word 引擎行为。

A = 改造前（V6.3.x 线上行为）：整封邮件 1 张外层表格 + 1 张嵌套表格，
    里面每行图片各占一条 <tr>，行与行之间会被 Word 引擎塞进约 1px。
B = 改造后：整封邮件只有 1 张表格、1 条 <tr>，每个竖列一个 <td>，
    列内用 display:block 连续堆叠 —— 和普通长图（已验证无缝）同一套写法。
